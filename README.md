# CRUD Products System

A simple product management system for stores using HTML, CSS, and JavaScript.

## Features
- Add new products (Name, Category, Price, Stock, Description).  
- Edit existing products directly in the table.  
- Delete products easily.  
- Save data automatically using `localStorage`.  
- Simple and clean user interface with a table to display products.

## How to Use
1. Open `index.html` in your browser.  
2. To add a product, click "+ Add Product", fill out the form, and click "Add Product".  
3. To edit a product, click "Edit" in the table, modify the data, and click "Confirm".  
4. To delete a product, click "Delete".  
5. All data will be automatically saved in the browser.

## Technologies Used
- HTML / CSS / JavaScript  
- LocalStorage for data persistence
